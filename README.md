ПР7. Ответы на контрольные вопросы

1. Содержимое ячейки памяти, которая выделена под переменную-аргумент.

2. Кто именно обязан инициализировать переменную до вызова или внутри себя.

3. Под out не обязательно инициализировать переменную, но обязательно заполнить её, а под ref нужно создавать переменную и инициализировать. Это неудобно.

4. Модификатор in решает проблему производительности при сохранении безопасности данных.

5. После всех обязательных параметров.

6. Именованные аргументы позволяют выборочно передавать только нужные необязательные параметры в любом порядке.
